# Sana Bir Evren Sakladım

Romantik, sinematik, etkileşimli ve mobil uyumlu statik web sitesi.

## Çalıştırma
`index.html` dosyasını tarayıcıda açın. HTML, CSS ve JavaScript aynı klasörde olmalıdır. Google Fonts bağlantısı için internet gerekebilir; çevrimdışıyken yedek sistem fontları kullanılır.

## GitHub Pages
Dosyaları repository kök dizinine yükleyin. Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Özelleştirme
Mektup metnini `index.html` içindeki `letter-panel` bölümünden değiştirebilirsiniz. Renkleri `style.css` dosyasından düzenleyebilirsiniz.

## Not
Site herkese açık GitHub Pages üzerinde yayınlandığında mektup içeriği de herkese açık olur. Tasarım sıfırdan hazırlanmıştır. Harici görsel kullanılmaz. Harici Google Fonts isteği yapılabilir.


Güncelleme: İlk ekranda yalnızca Hikâyeyi keşfet bağlantısı bulunur. Mektup yalnızca son bölümde açılır. Güneş motifi ve daha canlı yıldız animasyonu eklendi.
